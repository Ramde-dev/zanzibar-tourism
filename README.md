# Zanzibar Tourism

Static website for Prince Abuu Bakar Zanzibar Tours.

## Pages

- Home
- Tours
- Destinations
- Gallery
- About
- Booking

The site uses plain HTML, CSS, JavaScript, and local media in `assets/`. It can be hosted from the repository root with GitHub Pages.

Website pages use the compressed, resized JPEG copies in `assets/images/optimized/`.
The original photos remain in `assets/images/`. Keep both folders when hosting the site.
